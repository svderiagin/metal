# Полоса стальная — новые наименования

По запросу владельца от 08.11.2026 категория «Полоса» переименована в
«Полоса стальная», а все 19 товаров — по образцу «Полоса стальная 40×4 мм».
Исходное состояние: коммит `105829a`. Сохранённый импорт поставщика не изменён;
публичные названия применяются через `lib/flatSteel.ts` и catalog overrides.
Идентификаторы, URL, цены, единицы и характеристики сохранены.

В 19 действующих иллюстрациях заменена только область заголовка тем же
комплектным Inter, цвет `#41464D`. Все пиксели вне неё, включая металл,
характеристики и схему сечения, совпадают с исходными. Файлы сохранены lossless
WebP 2400×1800. Прежний рецепт удаления № и его архивы остаются историческими.

`before/` и `after/` содержат полные иллюстрации. `result.json` хранит имена,
подписи каталога и хеши; `renamed-products.json` — соответствие старых и новых
названий. Просмотрены все заголовки на `headings.png`, полный вариант 100×10
и его нативное сравнение `comparison-100x10.png` до применения на сайте.

Подготовка и применение просмотренных файлов:

```sh
node scripts/rename-flat-steel-illustrations.mjs
node scripts/rename-flat-steel-illustrations.mjs --apply-reviewed
node scripts/catalog-image-versions.mjs
```

Вручную проверены название категории, таблица, поиск `40x4` / `40×4`,
добавление и название товара в корзине, мобильная карточка при ширине 390 px
и увеличенная иллюстрация с версионированным URL. Добавленная для проверки
позиция из корзины удалена. Скриншоты `site-*` фиксируют результат.
Поля всех товаров кроме 19 названий сравнены с исходным состоянием;
характеристики иллюстраций и состав каталога сохранены, подписи всех 19
иллюстраций и названия в проекции корзины актуальны.
Тесты, сборка и линтер не запускались по указанию владельца.
