# Запуск приложения

Сохранён существующий Node-процесс Next.js: `npm run build` → `npm run start`.
Статический экспорт не включён: маршрутам `/api/*` и оптимизатору изображений нужен сервер.

Для DigitalOcean App Platform используйте тип Web Service, корень этого репозитория,
build command `npm run build`, run command `npm run start` и Node.js 22.x из `package.json`.
`next start` принимает порт из `PORT`; он должен совпадать с HTTP-портом, заданным для сервиса.
Стандартный hostname Next.js — `0.0.0.0`. Для локальной проверки допустим явный `--hostname 127.0.0.1`.
Проверка HTTP-доступности может обращаться к `/`.

Настройки App Platform хранятся в панели DigitalOcean. Для заказов и PDF
подключите постоянную базу PostgreSQL в том же проекте и задайте переменные
уровня Web Service с областью `RUN_TIME`:

| Переменная | Значение для компонента базы `orders-db` |
| --- | --- |
| `ORDER_DATABASE_URL` | `${orders-db.DATABASE_URL}` |
| `ORDER_DATABASE_CA` | `${orders-db.CA_CERT}` |
| `INVOICE_MODE` | `live` |
| `INVOICE_BANK_ACCOUNT` | Расчётный счёт магазина из банковской карточки реквизитов |
| `INVOICE_VAT_RATE` | `22` |
| `INVOICE_PRICES_INCLUDE_VAT` | `true` |

Уберите `ORDER_STORAGE_DIR` после проверки, нужно ли перенести прежние заказы.
Локальный диск контейнера очищается при замене экземпляра. Оставьте доступ
к базе только доверенным сервисам и настройте резервное копирование.
На отдельном проверочном стенде создайте тестовый заказ,
скачайте PDF, проверьте `404` без токена и сравните контрольную сумму PDF
после перезапуска. Подробности в [документации по счетам](invoice-generation.md).

В сборку должны входить папка `public`, локальные `data` и файлы приложения;
скачанное зеркало поставщика не требуется для сборки и запуска.

Команда `prebuild` обновляет хеши изображений и готовит адаптивные AVIF/WebP для главной и каталога.
При копировании сборки на сервер включайте `public/images/prepared/` вместе с остальной папкой `public`.
Секреты не должны иметь префикс `NEXT_PUBLIC_`.

Создание заказа и скачивание сохранённого PDF работают без SMTP. Без настроенного
почтового адаптера отправка письма отмечается отдельно. Для онлайн-оплаты картой
нужен платёжный провайдер.

Локальная production-проверка:

```sh
npm run test:unit
npm run lint
npm run test:build
npm run test:e2e
```

Playwright запускает локальную production-сборку на `127.0.0.1:3100` и подменяет
запросы форм. Отчёт доступен через `npx playwright show-report`.
