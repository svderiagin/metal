# Теоретическая масса профильных труб

Обновлено 24.11.2026. Масса для 34 квадратных и 27 прямоугольных труб внесена из опубликованных таблиц по точному сочетанию наружных размеров и номинальной толщины стенки. Расчётная подстановка по формуле не используется.

Выбор справочной теоретической массы погонного метра не определяет фактическую массу партии, стандарт её изготовления, марку стали, производителя или наличие.
