# Теоретическая масса профильных труб

Проверено 07.11.2026. Масса для 28 квадратных и 23 прямоугольных труб внесена из опубликованных таблиц по точному сочетанию наружных размеров и номинальной толщины стенки. Расчётная подстановка по формуле не используется.

Это справочная теоретическая масса погонного метра, а не результат взвешивания партии. Выбор справочной таблицы не присваивает товару стандарт изготовления, марку стали, производителя или подтверждённое наличие. Коммерческие цены и заказ целыми трубами не меняются.

## Изображения и воспроизводимость

Иллюстрации 4:3 пересоздаются прежним генератором только для 51 затронутого артикула. Фото, палитра, шрифт и размещение сохранены; добавлено значение массы. Генератор теперь допускает `--write` вместе с явными ID и объединяет изменённые записи манифеста с остальными семействами.

Снимок `imports/protected-catalog.snapshot.json` обновлён только для этих 51 позиций: добавлены масса, флаг подтверждения опубликованного значения и соответствующая спецификация. Перед записью проверено отсутствие остальных изменений в каждой из этих записей.
