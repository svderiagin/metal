# Контент rozmet.ru, 18 октября 2026

Импортировано 14 категорий, 6 реальных подкатегорий и 333 уникальных товара. Данные защищённых шести категорий не меняются.

- Исходные поля карточек и разделов: `imports/rozmet-source.json`.
- Структура, счётчики и пропуски: `imports/rozmet-manifest.json`.
- Снимок защищённых данных, типов продукции и хешей изображений: `imports/rozmet-protected.snapshot.json`.
- Публичный набор: `data/rozmet-catalog.json`; прямые маршруты листовых категорий: `data/rozmet-routes.json`.
- Изображения: `public/images/catalog/rozmet/`; имена вычисляются из исходного URL.

Двенадцать категорий источника содержат товары напрямую. Для них используется существующая таблица на странице категории. Внутренние адаптеры `Subcategory` помечены `internal: true`, скрыты из навигации и не создают покупателю дополнительного уровня. Настоящие подкатегории листового проката и арматурных изделий сохранены.

Обычная текущая цена берётся из видимого блока карточки и сверяется с её JSON-LD. Старые цены не импортируются. Единицы: штука, погонный метр, квадратный метр, килограмм. Явные условия оплаты сохранены в характеристиках. Отсутствующие описания и фотографии не заменяются выдуманными данными.

Повторная генерация из сохранённых исходных полей:

```bash
node scripts/import-rozmet.mjs
node --test scripts/rozmet-catalog.test.mjs
```

Обновление публичного источника выполняется только по запросу на новый импорт:

```bash
python3 scripts/collect-rozmet.py --refresh --images
node scripts/import-rozmet.mjs
```

Коллектор использует стандартную библиотеку Python и curl, не выполняет JavaScript источника. HTML-кеш находится в `.tmp/rozmet-source/pages`. Четырнадцать разделов выбираются из дерева `/production/`, шесть защищённых разделов исключены по исходным URL. Проверена пагинация фитингов. Повторы карточек в родительских и дочерних таблицах удаляются по исходному URL.

## Проверка характеристик швеллеров, 19 октября 2026

Свежие вкладки и описания всех 14 товаров сохранены в `imports/shveller-specifications.source.json`. Противоречия источника и сверенные значения записаны в `imports/shveller-specifications.verified.json` со ссылками на Росстандарт, текст ГОСТ 8240-97 и сортамент ЕВРАЗ Стил Инжиниринг.

В `data/channel-specifications.json` находятся номинальные высота, ширина полки, толщина стенки и полки, теоретическая масса по таблицам 1–2 ГОСТ. Для выбранных номеров эти величины совпадают у серий У/П; фактическая серия и соответствие партии не подтверждены. Это пояснение показано над таблицей и в карточке товара. Масса № 6,5 исправлена с ошибочных 4,84 кг в тексте поставщика на 5,90 кг/м; у № 5 высота 50 мм отделена от ширины полки 32 мм.

Длина поставки не выводится из сортамента: используется поле «Длина» вкладки поставщика, при его отсутствии — «Размер», с подписью «Длина по каталогу». Публичный адаптер `data/products/index.ts` применяет уточнения только к совпавшим ID и URL швеллеров. Исходный импорт, цены, единицы, изображения, остальные категории и коммерческие поля сохраняются. Условия наличной оплаты из исходного импорта скрыты в интерфейсе по отдельному указанию владельца.

По следующему указанию владельца для № 5 подключена очищенная иллюстрация через поле `imageUrl` в этом же адаптере; исходный файл сохранён. Задание и финальный промпт: `imports/shveller-5-image-edit.md`. Миниатюры всех швеллеров открывают существующий `ProductImageViewer` в режиме предпросмотра: изображение, короткое описание и справочный стандарт без дублирования характеристик. Сохранённые прямые URL товаров остаются доступными.

Для № 6,5 по присланному владельцем образцу добавлена иллюстрация в той же стилистике; характеристики, цена и остальные поля товара сохранены. Исходный образец и промпт: `imports/shveller-6-5-image-edit.md`.

Утверждённый шаблон № 6,5 применён ко всем 14 швеллерам: подготовлены 13 остальных изображений с индивидуальными проверенными подписями. В `imports/shveller-template-images.json` сохранены параметры, промпты встроенного `image_gen` и пути результатов. Итоговые WebP находятся в `public/images/catalog/shveller/` и подключены через `data/channel-specifications.json`. Исходные изображения поставщика сохранены. В таблице добавлена отдельная колонка «Наименование» с короткими номерами, миниатюры увеличены до 176 × 132 px; заголовок и содержимое характеристик выровнены по левому краю с одинаковыми отступами.
