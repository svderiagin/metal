## Упрощение и удалённые остатки

- Чистая работа с сохранённой корзиной вынесена в `lib/cart.ts`; React context управляет состоянием и хранением.
- Столбцы арматуры и балки теперь два обычных явных массива; удалена привязка к числовым позициям чужих столбцов.
- В измеряемой таблице удалены повторный поиск, промежуточные `Set`/`Map` и сортировка по восстановленным рангам:
  используется уже упорядоченный результат того же поискового индекса. Морфология и технический разбор не изменены.
- Удалены `VariantAttributeColumn`, нечитавшиеся `columns`, `pipePresentation`, неиспользуемые
  `getProductTypeCountByCategoryId` и `totalQuantity`, повторная проверка `isMeasuredRebarVariant`,
  закомментированные пункты меню. Проверены ссылки в исходниках, тестах, package scripts и документации;
  это не маршруты и не имена, используемые генерацией/динамическим импортом. Упоминания старой корзины в README
  явно отмечены как исторические.
- Удалены три одинаковых `readError`, no-op класс уведомлений и дублирующая проверка атрибутов типов.
- Устаревшие браузерные проверки искали удалённые кнопки паузы/счётчики, ожидали старые тексты,
  писали результаты в `imports`, закрывали весь Chrome или создавали временные публичные фотографии.
  Их имена сохранены как совместимые входы в `check-local-browser.mjs`. Проверка JPEG/AVIF/WebP
  в `check-hero-images.mjs` сохранена. Документация обновлена; входы больше не перезаписывают фотографии и evidence.
- Исправлен ESLint ignore: настоящее имя локального зеркала `brokinvest.ru`, а не `www.brokinvest.ru`.
  Ни зеркало, ни исходные данные, фотографии, импортные инструменты, рабочие маршруты и функции не удалялись.

## Сохранённые ограничения и действия владельца

- Настоящая доставка сообщений, постоянное хранение заказов, оплата и webhook не настроены. Для реальных заявок
  потребуется выбрать и подключить канал доставки; для платежей — соответствующую интеграцию.
  Реальные клиентские заявки и платежи во время аудита не отправлялись.
- Каталог содержит 117 описаний демонстрационных позиций и исторический расчётный вес у части записей.
  Их фактический статус не подтверждён владельцем; записи не удалялись, характеристики не исправлялись догадками.
  Высокие цены электродов также сохранены согласно имеющейся документации источника.
- Текущий importer отличается от сохранённого каталога: он меняет описания четырёх подкатегорий балок и manifest.
  Требуется отдельное согласование источника описаний перед следующим намеренным импортом.
  Во время аудита опубликованный каталог восстановлен и не изменён.
- Исходное зеркало поставщика и два отчёта изображений отсутствуют. Проверка provenance по их байтам не выполнена;
  вернуть материалы нужно только для этой проверки/работы с источником, не для запуска сайта.
- Установлен Node 25.9.0. Требование Node 22.x сохранено; отдельный запуск под Node 22 и удалённая среда
  DigitalOcean не проверялись. Проверен локальный `next start` с production-сборкой и явным портом.
- CLS, загрузочная производительность страницы, физическая смена вкладок и поведение на реальном телефоне
  отдельно не измерялись. Эмуляция Chrome не заменяет такие измерения.
