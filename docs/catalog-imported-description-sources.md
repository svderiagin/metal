# Описания импортированного каталога после «Швеллера»

В [витринных текстах](../data/catalog-imported-description-copy.ts) `intro` кратко объясняет, что продаётся на странице. Его достаточно для первого экрана, на котором также нужны фильтры или ссылки на подкатегории. Раздел `title` и `details` ниже списка объясняет, как сопоставить размеры и характеристики с задачей. Для подкатегорий используются исходные ID, в том числе исторический `rozmet-sub-listovoy-prokat-list-ocynkovannyj` для холоднокатаного листа.

Состав ассортимента и обозначения сверены с [импортом Розмет](../data/rozmet-catalog.json) и публичными правилами [видимости товаров](../data/catalog-visibility.ts). Ссылки ниже подтверждают терминологию и способы подбора. Соответствие конкретной позиции ГОСТ, совместимость, допустимые нагрузки и другие требования определяются по документации позиции и проекту.
