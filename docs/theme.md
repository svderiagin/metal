# Цветовая тема

Кнопка в шапке переключает три режима по кругу: светлый → тёмный → системный.
Солнце обозначает светлый режим, луна — тёмный, круг со светлой и тёмной половинами — системный.
Подсказка и доступное имя сообщают текущий режим и действие следующего нажатия.
Кнопка размером 44×44 px работает с клавиатуры (Enter/пробел) и на сенсорном экране.
По умолчанию используется системная тема. После первого нажатия явный выбор
хранится в `localStorage` под ключом `rvb-theme`. Системный режим удаляет этот ключ
и автоматически следует настройкам операционной системы.

## Реализация

- `lib/theme.ts`: небольшая начальная установка темы в `<head>` до отображения
  содержимого; системные изменения, синхронизация вкладок и временный выбор при
  недоступном хранилище. Хранятся только значения `light`/`dark`.
- `components/layout/ThemeSwitch.tsx`: нативная кнопка и `useSyncExternalStore`.
  Серверный снимок стабилен, браузерные API не вызываются при серверном рендере.
- `app/layout.tsx`: ранний скрипт и `suppressHydrationWarning` только на `<html>`,
  поскольку скрипт намеренно устанавливает его `data-theme` до гидратации.
- `app/globals.css`: селектор Tailwind `dark:`, `color-scheme` и переменные
  семантических состояний. Сброс цветов ссылок находится в базовом CSS-слое,
  чтобы не перекрывать цвета ссылок-кнопок.
- Компоненты используют явные `dark:` варианты. CSS Modules форм и кнопок
  используют переменные темы. Геометрия страниц, данные и фотографии сохранены;
  изображения не инвертируются и не затемняются фильтром.

Новых зависимостей, провайдера на всё приложение и запросов к серверу нет.
При добавлении элементов задавайте тёмные цвета для поверхности, текста,
границ и интерактивных состояний; не меняйте общие цвета палитры Tailwind.

## Проверка

`scripts/theme.test.mjs` проверяет начальную тему, приоритет сохранённого выбора,
системные изменения, синхронизацию вкладок, очистку подписок и заблокированное
хранилище. Полный набор: 122 успешных теста, 3 штатных пропуска.
TypeScript, ESLint и production-сборка проходят.

В браузере проверены desktop, ширины 320/390 px, светлый/тёмный режимы,
перезагрузка и переходы, каталог, мобильное меню, таблицы, поля и корзина.
На проверенных экранах горизонтального переполнения нет; в production нет
зарегистрированных предупреждений/ошибок гидратации. Измеренный контраст основных
текстовых пар тёмной палитры — от 6,45:1, границы поля — 3,75:1; это не полный
аудит всех состояний по WCAG.

Источники: [Tailwind: Dark mode](https://tailwindcss.com/docs/dark-mode),
[React: useSyncExternalStore](https://react.dev/reference/react/useSyncExternalStore),
[React: hydrateRoot](https://react.dev/reference/react-dom/client/hydrateRoot).
