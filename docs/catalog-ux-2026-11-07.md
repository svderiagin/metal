# Каталог: решения по аудиту 07.11.2026

Запрос: уменьшить повторяющиеся титульные фотографии, приблизить выбор товара,
добавить полезную техническую информацию и сохранить понятный заказ.
Дополнительное уточнение владельца: два визуальных формата товарной таблицы.

## Принятая структура

- Категория с подкатегориями: заголовок и краткое введение с небольшим фото,
  карточки подкатегорий, рекомендации по выбору, переход к запросу расчёта.
  Четыре подкатегории арматуры располагаются сеткой 2 × 2 на компьютере.
- Страница с товарами: компактная навигация, введение, поиск и сортировка,
  раскрываемые параметры, товары, технические рекомендации, форма расчёта.
  Длинное боковое меню не отодвигает широкую таблицу вниз.
- Титульные фото сохраняют собственные галереи, увеличение, 1:1, перемещение,
  закрытие клавишей Escape и возврат фокуса.
- Размер титульного фото ограничен 320 px на компьютере, 200 px на планшете,
  192 px на телефоне. Фотографии поставщиков не обозначаются как собственный склад.
- Параметры подбора свёрнуты; поиск, сортировка, число результатов и сброс видны.
  Выбранные параметры отмечаются счётчиком даже в закрытой панели.

## Два формата таблицы

| Формат | Содержимое | Адаптация для телефона |
| --- | --- | --- |
| Арматура | 10 колонок: диаметр, форма, марка стали, цена за тонну, масса, длина, заказ в метрах и тоннах, сумма, действие. Без изображений. | Карточка с теми же характеристиками и двумя полями заказа, без фото. |
| Изделия по образцу швеллера | Название, изображение со схемой размеров, характеристики, цена, поля заказа, сумма и действие. Состав характеристик и единиц зависит от семейства. | Компактная размерная миниатюра 160 px рядом с названием, характеристики и заказ ниже. |

У второй таблицы применяются готовые проверенные размерные иллюстрации.
Схема показывается и в миниатюре, и в увеличенном просмотре. Разметка не создаётся
из предположений о недостающих размерах. Существующие фотографии и исходники сохранены.
Правила разметки и проверки — [catalog-images.md](catalog-images.md).

Заказ и валидация остаются общими по смыслу: допустимое количество, объяснимая
коррекция, расчёт по подходящей единице, явное добавление/обновление корзины.
Нормальное выделение поля сине-серое; красное обозначает ошибку.

## Содержание

`data/catalog-description-copy.ts` содержит отдельный слой витринных текстов.
Исходные описания поставщиков остаются в каталоге без переписывания evidence.
Для всех 20 категорий и открытых подкатегорий есть короткое введение и рекомендации
после товаров. Карточки используют то же введение, что и целевая страница.

Тексты объясняют, какие размеры сравнивать и что включить в запрос. Класс арматуры
отделён от марки стали; для труб разделены Ду и наружный диаметр; для листов
уточнены формат, толщина и покрытие. Несущие сечения и узлы выбираются по проекту.
Индивидуальные пустые описания не заполняются повторяющейся рекламой: основными
данными позиции остаются её характеристики и проверенная размерная схема.

Для заказа обработки указаны исходные данные чертежа/ведомости. Для доставки —
адрес, объём, максимальная длина, подъезд и разгрузка. Не добавлены неподтверждённые
сроки, тарифы и адрес склада.

## Достоверность предложений

`lib/catalogOffer.ts` ограничивает использование исходных записей в витрине,
агрегатах карточек, ценовых фильтрах и авторитетном пересчёте корзины/заказа.

- 13 демонстрационных записей: 6 ранее помечены флагом, 7 определяются по ID.
  Неподтверждённые предложения показываются с запросом цены.
- У `prd-003` и `prd-004` сохранены подтверждённые владельцем 50 000 ₽/т.
  Их исходные масса и марка стали не считаются подтверждёнными. Заказ в тоннах
  доступен; пересчёт по демонстрационной массе не применяется.
- У 8 позиций единица исходной цены противоречит описанию упаковки/рулона/детали.
  Они доступны через запрос цены с пометкой об уточнении единицы продажи.
  Новая единица и цена не угадываются.
- Старые записи корзины проходят те же проверки. Сохранённая в браузере цена
  не обходит ограничение.

Для снятия ограничения с неоднозначной единицы нужны подтверждённые данные
конкретного предложения и соответствующая правка реестра с проверкой заказа.
Публичные ID, цены в исходных данных и защищённый snapshot сохранены.

## Контакты и интеграции

Владелец подтвердил `sales@rwb-metal.ru`. Email опубликован в шапке, подвале,
контактах и блоках расчёта. Телефон пока обозначен текстовой заглушкой.
Юридический адрес не используется как адрес самовывоза.

Оплата картой отмечена как пока недоступная и не выбирается в форме. По умолчанию
выбран счёт. Платёжный адаптер остаётся ненастроенным, успешная оплата не имитируется.

Почтовый адаптер пока не подключён. Формы сохраняют данные при отказе API и
показывают прямую ссылку на email. Публикация адреса не означает автоматическую
отправку писем. Для её подключения нужен почтовый сервис и серверные доступы.
Реальные сообщения и платежи во время проверки не отправляются.

## Основания решений

Приоритет ссылок на подкатегории и ориентации в ассортименте соответствует
[исследованию Baymard о категориях](https://baymard.com/blog/ecommerce-category-page).
Компактное фото и свёрнутые параметры — проектное решение для данного каталога,
а не универсальное требование исследования.

Профессиональные примеры для сравнения: [табличный каталог А500С МС24](https://mc24.ru/production/metalloprokat/armatura/a500c/)
и [каталог профлиста «Металл Профиль»](https://metprof.ru/catalog/proflist/).
Технические источники импортированных семейств перечислены в
[отдельной справке](catalog-imported-description-sources.md).

## Проверка результата

Положение первой карточки/строки от начала страницы, px; одинаковые viewport
до и после: компьютер 1440 × 1000, телефон 390 × 844.

| Страница | Компьютер: до → после | Телефон: до → после |
| --- | --- | --- |
| Категория «Арматура» | 895 → 539 | 779 → 710 |
| А500С | 1742 → 937 | 2043 → 1105 |
| Квадратные профильные трубы | 1694 → 915 | 1913 → 1105 |
| Швеллер | 1768 → 995 | 1872 → 1224 |

Это измерения конкретных страниц, а не обещание одинаковой высоты для любого
шрифта, увеличения текста и ассортимента.

- `npm run test:unit`: 193 успешных, 3 прежних предусмотренных пропуска.
- `npm run test:coverage`: 93,40% строк / 90,60% ветвей / 88,38% функций
  загруженного ядра; пороги выполнены.
- `npm run lint`, `npx tsc --noEmit --incremental false`,
  `npm run test:build`: успешно.
- Полный E2E: 390 успешных, 2 пропуска desktop-проектов для mobile-only сценария.
  Дополнительный прогон изображений после включения размерных миниатюр:
  32 успешных в четырёх проектах экрана/темы.
- Финальный обход 54 страниц в двух размерах: 108 успешных ответов;
  не обнаружены JS-ошибки, ошибки загрузки изображений и переполнение страницы.
- Вручную просмотрены компоновка «Арматуры», мобильные карточки, размерные
  миниатюры и обновлённые контактные данные в обеих темах. Увеличенные изображения
  сохраняют проверенные эталоны fit/1:1.
- Существующие эталоны сначала сравнены: ожидаемые отличия просмотрены,
  соответствующие PNG обновлены. Повторное сравнение без обновления:
  `npm run test:visual` — 60 успешных сценариев, 72 PNG.
- Каталог: 20 категорий, 38 подкатегорий, 570 позиций, сирот нет;
  защищённые категории, подкатегории и товары совпадают с snapshot побайтно.

Команды браузера используют `.next-test` и порт 3100, отдельные контексты,
локальные подмены API. Пользовательская корзина не использовалась; рабочий
dev-сервер не перезапускался.
