# Визуальное направление РВБ — 07.11.2026

Задача: обновить цветовую схему и оформление каталога для среднеоптовой продажи,
сохранив ассортимент, иерархию, два формата таблиц и логику заказа.

## Предложение и его реализация

Выбрано направление «графит и стальной синий». Светлая тема оформлена как нейтральная
рабочая поверхность для длинных таблиц; тёмная получила более светлые графитовые
панели вместо почти чёрного синего. Это дизайнерское решение для данного проекта,
а не утверждение об универсально лучшем цвете для оптовой торговли.
Режимы светлый/тёмный/системный и запоминание выбора сохранены.

До изменения красным одновременно выделялись действия, ссылки, заголовки,
выбранные варианты и отдельная категория. Большие скругления и тени делали карточки
самостоятельными визуальными блоками. Основная задача нового оформления — дать
снабженцу спокойно сравнивать размеры, цену и количество и быстро находить действие.

| Область | Решение |
| --- | --- |
| Цвет | Графитовые шапка и подвал, нейтральный фон, стальной синий для действий и ссылок. Ошибка и удаление остаются красными, сохранённый заказ — зелёным. |
| Геометрия | Поля и кнопки: 4 px; карточки и панели: 6 px; небольшие элементы: 2–3 px. Уменьшены тени, убрано подпрыгивание карточек при наведении. |
| Таблицы | Спокойная шапка с контрастным текстом, лёгкое чередование строк, подсветка строки при наведении/работе с полем. Панель подбора занимает ширину таблицы. |
| Типографика | Локальный Inter сохранён. H1 — 600 вместо 700; базовые размеры 16/15/13 px и табличные цифры сохранены. Поля — 16 px. |
| Плотность | Компактнее шапка, меню категорий и интервалы главной. Минимальная высота первого блока главной уменьшена с 600 до 480 px на компьютере; длинный текст продолжает растягивать блок. |
| Действия | «Запросить расчёт» в шапке; основные кнопки заполнены, вторичные имеют спокойную границу. Сброс фильтров перестал конкурировать с заказом. |
| Фокус | Указатель сохраняет нижнюю сине-серую линию поля, клавиатура — заметный контур. Ошибка обозначается красным и текстом. |

Круглые счётчики и кнопки управления галереями сохранены. Увеличенное фото
сохраняет ранее согласованное закруглённое окно 28 px, 1:1 и возврат фокуса.
Фото и подписи на готовых размерных схемах не перекрашиваются и не регенерируются.

## Палитра

| Назначение | Светлая тема | Тёмная тема |
| --- | --- | --- |
| Фон страницы | `#F2F4F5` | `#141D25` |
| Панель | `#FFFFFF` | `#202B34` |
| Основной текст | `#202B34` | `#EDF0F2` |
| Основное действие | `#24566D` | `#3B7A90` |
| Текст основного действия | `#FFFFFF` | `#FFFFFF` |
| Шапка таблицы | `#E7EDEF` | `#303E49` |
| Выделение текста | `#BDD6E0` | `#BDD6E0` |

Белый текст основной кнопки: около 7,99:1 в светлой теме и 4,80:1 в тёмной.
Контраст измеряется по реальным цветам браузера в дополнительных E2E-тестах.
Для проверенных подсказок выполнен порог 4,5:1, для границ полей — 3:1.
Убрано дополнительное уменьшение прозрачности подсказок формы расчёта.
Это проверка выбранных компонентов, а не полная сертификация сайта по WCAG.

Палитра `brand`, нейтральная шкала `slate`, радиусы и тени заданы централизованно
в `app/globals.css`. Основные кнопки используют семантические переменные,
а товарные состояния сохраняют собственные цвета. При дальнейших изменениях
следует применять эти роли и общие компоненты, не добавлять отдельную палитру
для очередной категории.

## Что изучено

- [MCB](https://www.mcb.eu/en): поиск и категории вынесены в основную навигацию,
  синий используется как фирменный акцент на нейтральной основе. Просмотрены
  публичная страница и доступная навигационная часть интерфейса.
- [Klöckner Metals Germany](https://shop.kloeckner.de/): отдельный выбор формы
  материала, крупные прямоугольные области, нейтральные поверхности.
  Часть обзора ограничена cookie-диалогом; закрытый личный кабинет не исследовался.
- [«Металл Сервис», А500С](https://mc24.ru/production/metalloprokat/armatura/a500c/):
  табличный подбор с единицами, количеством и итогом. Изучена публичная таблица;
  её красная палитра и шрифт не копируются в РВБ.
- [NN/G: визуальная иерархия](https://www.nngroup.com/articles/visual-hierarchy-ux-definition/):
  значимость задаётся сочетанием контраста, размера и группировки. Ограниченное
  количество акцентов помогает различать основные и вторичные элементы.
- [NN/G: плоский дизайн](https://www.nngroup.com/articles/flat-design/):
  при уменьшении декоративности необходимо сохранять признаки интерактивности.
  Поэтому у кнопок и полей остаются границы, заливки и состояния.
- [W3C: контраст текста](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html):
  обычный текст — не менее 4,5:1; для большого текста допускается 3:1.
  [Границы значимых компонентов](https://www.w3.org/WAI/WCAG22/Understanding/non-text-contrast.html)
  проверяются относительно окружающей поверхности с порогом 3:1.

Это экспертный обзор и реализация визуальной системы. Исследование реальных
покупателей и A/B-тест конверсии не проводились. После запуска полезно отдельно
измерить время подбора позиции и долю успешно составленных заявок.

## Проверка

- `npm run test:unit`: 193 успешных, 3 прежних предусмотренных пропуска.
- После изменения формы и первого экрана повторены связанные unit-проверки:
  3 успешных.
- `npm run lint`, `npx tsc --noEmit --incremental false`,
  `npm run test:build`: успешно.
- Полный `npm run test:e2e`: 426 успешных, 2 штатных пропуска desktop-проектов
  для мобильного сценария. После последней коррекции контраста повторены
  32 сценария оформления, доступности текста и фокуса — успешно.
- Обход 54 страниц в размерах 1440 × 1000 и 390 × 844: 108 ответов 200,
  не обнаружены JS-ошибки, ошибки изображений и горизонтальное переполнение.
- Дополнительно проверены 320, 1024, 1279 и 1280 px, загрузка локального шрифта,
  его отказ, увеличение текста до 200%, основные состояния товарной кнопки.
- Визуальные отличия сначала сравнены со старой темой. Обновлённые 72 PNG
  просмотрены в обоих размерах и темах, включая таблицы девяти семейств,
  главную, каталог, корзину, checkout и просмотр изображений fit/1:1.
  Повторное `npm run test:visual` без обновления — 60 успешных сценариев,
  72 PNG.
- Проверка каталога: 20 категорий, 38 подкатегорий, 570 позиций, сирот нет.
  Защищённые данные совпадают с snapshot побайтно. Исходные изображения,
  цены, единицы и расчёты этой задачей не менялись.

Браузерные проверки используют отдельный `.next-test`, порт 3100 и локальные
подмены API. Реальные заявки и платежи не отправлялись; пользовательская корзина
не использовалась. Тесты и просмотр выбранных экранов не заменяют исследование
поведения реальных покупателей.
