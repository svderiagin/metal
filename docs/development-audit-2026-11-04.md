# Аудит приложения — 04.11.2026

Область: каталог металлопроката, расчёты и корзина, оформление и API,
адаптивность и доступность, изображения, инструменты и навыки разработки.
Первый коммит `ea36d58` содержит исправления и декомпозицию **без запуска проверок**
по прямому указанию владельца. После него выполнен отдельный этап тестового
покрытия, проверки зависимостей и исправлений, найденных при этих проверках.

## Сохраняемые границы

- Утверждённые фотографии, их поверхности и размеры не перерисовываются.
  Исправление белой полоски сохраняется; отменённая галерея не возвращается.
- Цены, коммерческие единицы, идентификаторы, slugs и состав каталога не меняются.
  Уголки сохраняют те же публичные названия характеристик и значения;
  меняется только место применения отображаемой подписи.
- `originalCategories`, `originalSubcategories`, `projectCartProduct` используются
  import/test tooling и не удаляются по одному лишь отсутствию runtime consumers.
- Ненастроенные уведомления, платёжный провайдер и production-хранилище заказов
  по-прежнему требуют отдельного подключения. Возврат 503 сохраняется;
  настоящий успешный заказ или платёж не имитируется.
- Старые snapshots данных и фото не переписываются автоматически. Известные
  расхождения тестов анализируются на втором этапе относительно подтверждённой истории.
- В старых исходных вариантах остаются демонстрационные оценки массы без подтверждённой
  линейной массы. Они не используются для авторитетного расчёта заказа. Их удаление
  из защищённых данных требует отдельного разбора исходных фактов; новые расчёты их не вводят.

## Происхождение исправлений зависимостей и эталонов

При обновлении учитывались официальные advisories Next.js:
[Windows RCE](https://github.com/advisories/GHSA-p293-qw3h-jr36) и
[AVIF/libheif RCE](https://github.com/advisories/GHSA-2xp9-vwfh-vxw4).
Версии исправлений проверены относительно установленного пакета и lockfile;
после обновления повторно выполнены сборка и предметные/браузерные тесты.

Полный `npm audit` оставляет **16 moderate** предупреждений только в dev-цепочках
ESLint/minimatch: [globparts amplification](https://github.com/advisories/GHSA-g3hv-75wg-m249).
High/critical нет. Предложенный npm принудительный downgrade до ESLint 4 /
eslint-config-next 0.2.4 несовместим с текущей конфигурацией и не применялся.
Runtime-зависимости проверяются отдельно и чисты; оставшиеся dev-предупреждения
нужно пересмотреть при совместимом обновлении инструментов.

Четыре хеша сетки зафиксированы отдельно в `imports/protected-image-corrections.json`.
Для cover/карт найдены совпадающие байты в `aac0891`, для рабицы/рулонов — в
утверждённом обновлении `bbc7a7c`. Они сужают расхождение старого Rozmet image snapshot
до конкретных файлов, не меняя snapshot, фотографии, цены и состав каталога.

GitHub Actions workflow добавлен для lint/types, unit/API, покрытия, production audit,
сборки и E2E. Удалённый CI не запускался; macOS PNG сравниваются в совпадающей локальной
среде, собственных Linux-эталонов пока нет. Неподключённые провайдеры уведомлений,
оплаты и production order storage остаются явно отмеченными интеграционными задачами.
