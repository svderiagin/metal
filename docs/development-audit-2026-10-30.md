## Пять исходных ошибок тестов

1. `scripts/product-image-preview.test.mjs:64`: `framed` ожидается только для `rozmet-2235`, текущий компонент возвращает `true` и для других швеллеров. Нужна сверка с утверждённым оформлением.
2. `scripts/profnastil-catalog.test.mjs:57`: сравнение первых `indexOf` в исходнике страницы (`ProductTypeResults` и `detailedDescription`). Новая ветка другой категории делает такую проверку неоднозначной; реальный порядок блоков профнастила этим не установлен.
3. `scripts/rozmet-catalog.test.mjs:24`: повторный импорт во временную папку не совпадает с рабочим `data/rozmet-catalog.json`, где уже есть ручные правки. Слепой повтор импорта их затрёт.
4. `scripts/rozmet-catalog.test.mjs:39`: хеш `/images/catalog/setka-metallicheskaya/setka-main.jpg` отличается от `imports/rozmet-protected.snapshot.json`. Совпадение данных с другим snapshot не означает совпадения фотографий с этим.
5. `scripts/rozmet-catalog.test.mjs:67`: характеристика «Вес» у `rozmet-2209` не совпадает с сохранённой исходной карточкой. Нужно установить, какое уточнение авторитетно.
