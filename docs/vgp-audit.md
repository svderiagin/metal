Для семи проверенных записей использована таблица 1. Марка стали, производитель, резьба, муфты и тип длины не выводились из ГОСТ.

## Подтверждённые ошибки и исправления

- MS-0071 и MS-0072 — локальные демонстрационные записи из `data/products/trubaKruglayaLegacy.ts`, а не импортированные предложения.
  Их описания прямо называют позиции демонстрационными. ГОСТы относятся к другим видам продукции.
- Исходные объекты сохранены. `data/catalog-visibility.ts` исключает их по ID и SKU из общей публичной выборки, поиска,
  фильтров, генерации товарных URL и покупки. Сохранённая корзина с этими ID блокирует оформление и предлагает удалить позицию.
- Импорт использует тот же признак видимости. Семь исправленных записей и описание ВГП закреплены в `imports/overrides.json`.
  Проверка импорта работает во временной копии; рабочий каталог не регенерировался, скидка повторно не применялась к нему.
- `estimateDemoWeight` использовал `размер × 0,24` для труб, не учитывая полость и стенку.
  Применение к трубам прекращено. У 22 других локальных труб убрана только эта недостоверная масса; остальные поля не менялись.
- Для круглых стальных труб с явно заданными наружным диаметром D и стенкой t доступна формула
  `π × 7850 / 10⁶ × t × (D − t)` кг/м. Нужны положительные конечные D и t, `2t < D`.
  Табличная масса ВГП имеет приоритет над округлённой геометрической оценкой.
  Условный проход не используется вместо наружного диаметра. Для профильных и нержавеющих труб неизвестная масса не оценивается этой формулой.
- В общих карточках UNKNOWN раньше оставлял статус пустым. Теперь показано «Наличие уточняется».
  Неизвестное наличие не объявляется отсутствием. Единицы цены и расчёт корзины сохранены, НДС не выдумывается.

## Неподтверждённые предположения и недостающие сведения

- Высокие цены MS-0071/MS-0072 сами по себе не доказывают, какой должна быть цена или единица. Они не преобразовывались.
- «ТМ» приходит непосредственно из `rawOffers[].record.title` и `titleFull` поставщика;
  подтверждённой расшифровки в сохранённых данных нет. Исходный текст остаётся в приватном манифесте, в публичных характеристиках его нет.
- Нет документов партии для подтверждения марки стали, производителя, резьбы, муфт, исполнения длины,
  фактической массы, НДС и текущего складского остатка. Эти свойства не заполнялись.
- Актуальность сохранённых цен не проверялась; значения сохранены.

- После изменений: 74 теста, 70 успешных, 3 пропуска, 1 ошибка проверки изображений.
  Все пять новых тестов ВГП и существующие проверки поиска проходят.
- Единственная ошибка полного набора — отсутствующий `/images/catalog/truby-profilnye/pipe-square.jpg`.
  Во время работы изображения профильных труб переименованы в `truby-kvadratnie.jpg` и `truby-priamougolnie.jpg`,
  а привязки всё ещё используют прежние имена. Это отдельные изменения изображений вне аудита ВГП;
  вопрос об обновлении привязок направлен владельцу. Новые изображения и переименования сохранены.
- `npx tsc --noEmit`, `npm run lint`, `npm run build` — успешно.
- Браузер на уже работающем `127.0.0.1:3000`: все 7 сценариев ВГП успешны на ширине 1440/390 px:
  семь строк, характеристики, масса, ₽/т, неизвестное наличие, изображения ВГП, поиск,
  фильтры ГОСТ/размера, сортировка, сумма 0,5 т и блокировка архивной корзины.
  Ошибок JavaScript нет. Полный браузерный результат содержит 3 HTTP 400 для старого пути
  изображения профильных труб (`pipe-rectangular.jpg`) при посещении общего каталога.
- До точечной настройки dev-сервер отклонял WebSocket HMR с Origin `127.0.0.1` и клиент не гидратировался.
  Причина подтверждена запросом с Origin и кодом Next.js `block-cross-site-dev.js`;
  `allowedDevOrigins: ["127.0.0.1"]` исправляет её, сохраняя разрешённый по умолчанию localhost.
  Конфигурация относится к разработке и не меняет production-хостинг.
- Сверка публичных объектов с началом аудита: скрыты только два SKU; факты обновлены только у семи ВГП;
  у 22 других локальных труб удалена недостоверная масса. Остальные поля этих труб и все нетрубные товары сохранены.
- `git diff --check` успешен. Рабочий импорт, коммиты, push и deploy не выполнялись.
