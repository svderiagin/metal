# Источники товарных иллюстраций

Схема соответствий в [product-illustration-sources.json](../data/product-illustration-sources.json) задаёт фотографию для позиции или типа продукции. Если отдельного соответствия нет, иллюстрация использует существующую фотографию позиции из каталога. Галерейные кадры и ранее проверенные исходники перечислены в [документации галерей](catalog-cover-gallery.md). На фото может быть типовое изделие того же исполнения. Значения для разметки берутся из карточки выбранной позиции.

| Изделие | Файл |
| --- | --- |
| Оцинкованный профиль С8 | `c8-zinc.jpg` |
| Оцинкованный профиль С20 | `c20-zinc.jpg` |
| Тканая сетка 2 × 2 мм, вид переплетения | `fine-woven-mesh-2x2.webp` |
| Тканая сетка 5 × 5 мм | `woven-black-mesh-5x5.jpg` |
| Плетёная штукатурная сетка 14 × 14 мм | `plaster-galvanized-mesh-14x14.png`, `plaster-black-mesh-14x14.png` |

Для труб, арматуры, балок, швеллеров, уголков, квадрата, листов и полосы работают
отдельные генераторы с утверждёнными [шаблонами каталога](catalog-images.md#структура-каталога-изображений).
