# Структура каталога

Каталог строится из локальных данных. Иерархия состоит из категории, подкатегории, товарного семейства и позиции.

| Где менять | Что хранится |
| --- | --- |
| `data/categories.ts`, `data/subcategories.ts` | Навигация, описания, порядок категорий и подкатегорий. |
| `data/products/*.ts`, `data/catalog-positions.json` | Позиции арматуры, труб, профнастила, сетки и балок. |
| `data/additional-catalog.json` | Категории и позиции швеллера, уголка, квадрата, полосы, листового проката и штакетника. |
| `data/catalog-scope.ts`, `data/catalog-visibility.ts` | Границы основного ассортимента и скрытые позиции. |
| `data/productTypes.ts`, `data/direct-catalog-routes.json` | Семейства и категории, в которых таблица открывается сразу. |
| `lib/catalogOverrides.ts` | Правки отображения, характеристик и иллюстраций по идентификатору позиции. |
| `lib/catalogStandards.ts` | Ссылки на ГОСТы и таблицы стандартов на Меганорме. |

`data/products/index.ts` объединяет товарные записи, проверяет видимость и нормализует параметры семейства. `lib/catalog.ts` отдаёт витрине и серверу итоговые данные. Значения массы для расчёта хранятся с полной точностью. Правила ввода количества описаны в [catalog-order-inputs.md](catalog-order-inputs.md).

При изменении позиции сохраните её идентификатор, единицу продажи и ссылку. При согласованном переносе ключей проверьте переход из поиска и восстановление корзины. Ключи предыдущих версий разрешает `lib/catalogIdentity.ts`.

Добавляйте позиции с подтверждёнными характеристиками и ценами по указанию владельца. В товарных данных и описаниях используйте сведения о продукции и условиях её заказа. Внешние ссылки в каталоге ведут только на ГОСТы на Меганорме.

После изменения товаров или цен обновите проекцию корзины командой `node scripts/cart-catalog.mjs`. Для изображений следуйте [структуре каталогов и порядку обновления версий](catalog-images.md#структура-каталога-изображений). Для проверки количества позиций и связей категорий используйте `node .agents/skills/metal-frontend-catalog/scripts/catalog_state.mjs --summary`. Остальные проверки описаны в [рабочем процессе](development-workflow.md).

## Единицы в товарных таблицах

Применяйте один формат в заголовках, ценах, характеристиках, подписях полей заказа и соответствующих мобильных карточках всех категорий.

- Пишите `шт.` и `рул.` с точкой. В заголовках и значениях эта точка входит в сокращение, например «Заказ, шт.», «3 шт.» и «2 000,00 ₽/шт.».
- Пишите `мм`, `м`, `м²`, `кг`, `т`, `кг/м` и полное слово `лист` без точки. Краткие заголовки и значения оформляйте без завершающей точки, за исключением точки в сокращении.
- Показывайте единицу рядом с числовой ценой в каждой строке. Если все цены выражены в одной единице, указывайте её также в заголовке, например «Цена, ₽/т». При смешанных единицах используйте заголовок «Цена».

Переиспользуйте [`formatUnitPrice`](../lib/currency.ts) для цен и [`getQuantityUnit`](../lib/variantPresentation.ts) для единицы количества позиции.
