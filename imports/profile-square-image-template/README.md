# Изображения квадратных профильных труб

Эталон владельца от 07.11.2026:

- чистая фотография: `public/images/catalog/truby-profilnye/trubi_kvadratnie/truba_kvadratnaya_1448_1086_original.jpg` (1448 × 1086);
- образец разметки: `public/images/catalog/truby-profilnye/trubi_kvadratnie/truba_kvadratnaya_2400_1800_marked.jpg` (2400 × 1800).

Оба исходника сохраняются. `scripts/render-profile-square-images.mjs` готовит 28 изображений 4:3 в lossless WebP. Основа — размеченный эталон; только изменяемые числовые подписи заменяются фрагментами чистой фотографии и текстом. Фотография за пределами этих областей, постоянные части заголовка, подписи строк, стрелки и отражение остаются попиксельно неизменными. Толщина 1,5 мм в эталоне указана корректно.

Размеры, толщина стенки, длина/диапазон длины и подтверждённая теоретическая масса берутся из публичных `productVariants`. Массы и источники описаны в `docs/profile-pipe-weights.md`. Общая фотография иллюстрирует семейство; геометрия фотографии не масштабируется под номинальные размеры.

Шрифт — комплектный Inter через fontconfig, без контекстной замены буквы `x` знаком умножения. Цвет текста `#41464D`, размерных линий `#59636F`. Числа используют десятичную запятую и неразрывный пробел перед единицей. Метаданные и подписи каждого товара сохраняются в `rendered.json`.

```sh
node scripts/render-profile-square-images.mjs --preview profile-pipe-square-100x100x5
node scripts/render-profile-square-images.mjs --write
node scripts/catalog-image-versions.mjs
```

Перед пакетным выводом просмотрен вариант 100×100×5: заголовок, размеры, белая подложка толщины и жирные значения длины/массы сопоставлены с эталоном при масштабе 1:1. После генерации обязательны просмотр всех вариантов на контактных листах, деталей крайних размеров и проверки миниатюры/увеличения на сайте. Временные материалы проверки хранятся в `.tmp/profile-square-template-review/`.

Проверка 07.11.2026: просмотрены оба контактных листа (28 изображений), нативные детали 15×15×1,5, 50×50×1,5, 80×80×2 и 160×160×4. В действующей таблице и мобильной карточке 100×100×5 проверены миниатюра и увеличение; на компьютере также масштаб 1:1. Окно открывает версионный оригинал 2400 × 1800. У всех 28 файлов `protectedPixelChanges = 0`. Снимки сайта: `site-desktop-table.png`, `site-desktop-viewer.png`, `site-mobile-card.png`, `site-mobile-viewer-crop.png`. Тесты, сборка и lint не запускались по просьбе владельца.

Общий генератор `scripts/render-product-illustrations.mjs` пропускает `type-cat-trp-sub-1`, чтобы сохранить утверждённый шаблон. Изображения прямоугольных труб этим рендерером не изменяются.
