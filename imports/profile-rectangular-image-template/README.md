# Изображения прямоугольных профильных труб

Эталон владельца от 08.11.2026 сохранён в новой папке:

- чистая фотография: `public/images/catalog/truba-profilnia/truba_priamougolnaya/truba_priamougolnaya_1148_1086_original.jpg` (фактический размер 1448 × 1086);
- образец разметки: `public/images/catalog/truba-profilnia/truba_priamougolnaya/truba_priamougolnaya_2400_1800_marked.jpg` (2400 × 1800).

Имена и содержимое обоих исходников сохраняются. На размеченном образце
осталось слово «квадратная»; в производных изображениях заголовок исправлен
на «Труба профильная / прямоугольная № …» в основном проходе генератора.
По последующему запросу владельца знак № удаляется из всех 23 финальных
иллюстраций с сохранением исходных растровых глифов. См.
[запись коррекции](../number-sign-removal/README.md).

`scripts/render-profile-rectangular-images.mjs` использует тот же подход, что
утверждённый генератор квадратных труб: основа — размеченный эталон, а фон
изменяемых подписей берётся из чистого оригинала. Меняются только вторая
строка заголовка, значения наружных сторон, толщина стенки, длина и масса.
Размерные линии восстанавливаются только внутри этих областей. Фотография,
торец, внутренние стенки, стрелки, постоянные подписи, тень и отражение за
пределами областей замены сохраняются попиксельно. Генеративное редактирование
для разметки не применяется.

Размеры и длина берутся из текущего `productVariants`; теоретическая масса —
из подтверждённых значений каталога. Источники масс описаны в
`docs/profile-pipe-weights.md`. Генератор обслуживает 23 позиции с полной
спецификацией; старым позициям без полного сечения и толщины значения не
присваиваются. Фотография общая для семейства, а подписи показывают номинальные
параметры: геометрия фотографии под конкретное сечение не растягивается.

Шрифт — комплектный Inter через fontconfig. Контекстная подмена `x` знаком
умножения отключена. Цвет текста `#41464D`, линий `#59636F`. Используются
десятичная запятая и неразрывный пробел перед единицей. Файлы — lossless WebP,
2400 × 1800, 4:3, по прежним адресам товаров в `product-illustrations/`.
`rendered.json` хранит подписи, координаты, источники и проверку неизменности
за пределами областей замены для каждого файла.

```sh
node scripts/render-profile-rectangular-images.mjs --preview profile-pipe-rectangular-100x60x3
node scripts/render-profile-rectangular-images.mjs --write
node scripts/catalog-image-versions.mjs
```

Предварительный вариант 100×60×3 просмотрен целиком и в нативных фрагментах
рядом с эталоном: проверены заголовок, обе размерные подписи, толщина и масса.
Временные контактные листы и снимки сайта находятся в
`.tmp/profile-rectangular-template-review/`.

После генерации просмотрены оба контактных листа всех 23 изображений и нативные
фрагменты длинного заголовка, дробной толщины и массы. Для каждой позиции
`protectedPixelChanges = 0`. На сайте проверены миниатюра и увеличенный оригинал
100×50×3 на компьютере и в мобильной карточке; отдельно просмотрен масштаб 1:1.
Изображение в просмотрщике загружается по версионированному URL в размере
2400 × 1800. После переименования также просмотрены обложка категории,
карточки обеих подкатегорий и таблица квадратных труб. Снимки результата:
`site-desktop-viewer-crop.png`, `site-mobile-card.png`, `site-mobile-viewer.png`,
`site-native-zoom-crop.png`, `site-category-renamed.png`, `site-square-renamed.png`.
Тестовые наборы, сборка и линтер не запускались по просьбе владельца.

Подключение — через `data/product-illustrations.json` с актуальной сигнатурой
каталога. Общий генератор пропускает обе группы профильных труб, чтобы не
перезаписывать утверждённые шаблоны. Переезд изображений в `truba-profilnia`
отражён в источниках квадратного генератора, галереях, маппингах и метаданных;
URL страниц каталога остаются прежними.
