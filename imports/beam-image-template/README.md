# Иллюстрации балок

Четыре файла `public/images/catalog/balka/<семейство>/balka_<семейство>_2400_1800_marked.jpg` задают композицию, шрифт, стрелки и подписи для своих серий. Чистые фотографии находятся рядом: `balka_<семейство>_2400_1800_original.jpg`. В `templates.json` указаны семейства, эталонные профили и координаты подписей на холсте 2400 × 1800. Для 30Б1, 30Ш1, 30К1 и 30М WebP сохраняют все декодированные пиксели размеченных JPG.

Для других товаров меняются только отличающиеся подписи. Рендерер восстанавливает фон этих участков из исходной фотографии, сохраняет выносные линии, восстанавливает разрыв размерной линии под новой надписью и проверяет каждый пиксель вне заменённых участков. Для каждой серии используется одно изображение сечения. Стрелки показывают, где измеряется соответствующий размер.

## Данные для подписей

- Для Б, Ш и К размеры в миллиметрах и номинальная масса метра взяты из ГОСТ 35087-2024, таблица 1.
- Для М данные взяты из ГОСТ 19425-74, таблица 1. Указывается средняя толщина наклонной полки.
- Разметка и блок «Подробнее» берут размеры из одной [таблицы сечений балок](../../data/beam-sections.json). Перед нанесением числовых размеров рендерер проверяет стандарт позиции и сверяет табличную массу с каталогом. Длину поставки он берёт из строки товара.
- Если для позиции указан только ГОСТ 27772, выноски h, b, s и t обозначают параметры сечения. Числовые значения размеров требуют подтверждённого стандарта сортамента.

Повторная сверка всех 38 позиций и актуальности нормативных ссылок: [аудит от 21.11.2026](../../docs/catalog-specifications-audit-2026-11-21.md).

## Генерация

`node --import tsx scripts/render-beam-images.mjs` делает предварительные изображения и список подписей в `.tmp/beam-series/preview/`. Для выборочной проверки укажите идентификаторы позиций, например `local-110539 local-69356`. Для записи в каталог используйте `--write`, затем выполните `node scripts/catalog-image-versions.mjs`. Пути к товарам, изображениям и эталонам связывает `data/product-illustrations.json`.

Прежняя команда `scripts/render-beam-pilot.mjs` обрабатывает исходные четыре позиции с актуальными эталонами.
