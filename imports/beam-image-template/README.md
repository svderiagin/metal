# Иллюстрации балок

Четыре файла `public/images/catalog/balka/<семейство>/balka_<семейство>_2400_1800_marked.jpg` задают композицию, шрифт, стрелки и подписи для своих серий. Чистые фотографии находятся рядом: `balka_<семейство>_2400_1800_original.jpg`. В `templates.json` указаны семейства, эталонные профили и координаты подписей на холсте 2400 × 1800. Для 30Б1, 30Ш1, 30К1 и 30М WebP сохраняют все декодированные пиксели размеченных JPG.

Для других товаров меняются только отличающиеся подписи. Рендерер восстанавливает фон этих участков из исходной фотографии, сохраняет выносные линии, восстанавливает разрыв размерной линии под новой надписью и проверяет каждый пиксель вне заменённых участков. Для каждой серии используется одно изображение сечения. Стрелки показывают, где измеряется соответствующий размер.

## Данные для подписей

- Для Б, Ш и К размеры в миллиметрах и номинальная масса метра взяты из [ГОСТ 35087-2024, таблица 1](https://gostam.ru/pdfs/gost-35087.pdf#page=11).
- Для М данные взяты из [ГОСТ 19425-74, таблица 1](https://files.stroyinf.ru/Data2/1/4294852/4294852659.htm). Указывается средняя толщина наклонной полки.
- Значения для подтверждённого сортамента записаны по профилям в `sections.json`. Перед нанесением числовых размеров рендерер проверяет стандарт конкретного артикула и сверяет табличную массу с каталогом. Длину поставки он берёт из строки товара.
- У семи позиций указан только ГОСТ 27772 на сталь. Подпись «Справочная масса» показывает значение из справочника каталога для данного артикула. Выноски h, b, s и t обозначают размеры, которые требуют подтверждения. Поэтому у двух карточек 40Б1 разные подписи массы и размеров. Для демонстрационной позиции `prd-012` выводится пометка «Профиль и размеры уточняются».

Повторная сверка всех 38 позиций и актуальности нормативных ссылок: [аудит от 21.11.2026](../../docs/catalog-specifications-audit-2026-11-21.md).

## Генерация

`node --import tsx scripts/render-beam-images.mjs` делает предварительные изображения и список подписей в `.tmp/beam-series/preview/`. Для выборочной проверки добавьте артикулы, например `local-110539 local-69356`. Для записи в каталог используйте `--write`, затем выполните `node scripts/catalog-image-versions.mjs`. Пути к товарам, изображениям и эталонам связывает `data/product-illustrations.json`.

Прежняя команда `scripts/render-beam-pilot.mjs` обрабатывает исходные четыре артикула с актуальными эталонами.
